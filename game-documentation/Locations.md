# Locations
> This page is not complete!

 The map consists of up to 4 facilities per server, each controlled by a player. Facilities can be visited using the elevator. Each facility is made of 3 sectors unlockable with [/game-documentation/Research .](/game-documentation/Research)
 

In previous versions of SCP Architect X, there was an exterior map of the surface of the facilities. It was removed in v1.16.6 due to lag on older devices, and the fact that rarely anyone actually saw the exterior.
